# Rock Paper Scissors Game

## Description
This project is a simple Rock-Paper-Scissors game developed using Python. The user plays against the computer by choosing Rock, Paper, or Scissors.

The computer randomly selects an option, and the program compares both choices to decide the winner.

## Features
- User can choose Rock, Paper, or Scissors.
- Computer generates a random choice.
- Displays the winner of each round.
- Maintains user and computer scores.
- Supports multiple rounds.
- Provides an option to exit the game.

## Technologies Used
- Python 3
- Random Module

## How to Run
1. Install Python 3.
2. Download or clone this project.
3. Open the terminal.
4. Run the following command:

```bash
python rock_paper_scissors.py
```

## Sample Output

```text

Enter your choice: Rock
Computer choice: Scissors

Congratulations! You Win!

Your Score: 1
Computer Score: 0
```
